# Projeto-Agentes-IA
Projeto acadêmico de desenvolvimento de agentes de Inteligência Artificial utilizando Python.

## Instituição
Instituto Hardware BR.

## Etapa atual 
P0 - Desenvolvimento do classificador de mensagens em Python, com testes automatizados e versionamento em Git e GitHub.

O classificador utiliza atualmente regras baseadas em palavras-chave. A integração com uma API de modelo de linguagem (LLM) será realizada nas próximas etapas.

## Tecnologias 
Python
pytest (testes automatizados)
Git (controle de versões)
GitHub (repositório remoto)
Visual Studio Code (VS Code)

 ## Objetivo
Desenvolver uma aplicação em Python capaz de receber mensagens
do usuário, enviá-las a um modelo de linguagem (LLM) por meio
de uma API e apresentar a resposta no terminal.

Na primeira etapa preparatória, foi implementado um classificador
de mensagens baseado em palavras-chave, acompanhado de
testes automatizados com pytest.

O projeto também contempla organização do código,
versionamento com Git e GitHub, documentação e
registro dos testes realizados.
